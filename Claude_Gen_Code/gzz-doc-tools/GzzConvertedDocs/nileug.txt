2. Keystrokes
-------------

Unlike most current word processors, Nile has several different modes. This
may seem complicated but the modes are fairly natural. The most commonly used
modes are the character, word and sentence modes, through which the user can
move with the TAB key. In these modes, the following cursor keys apply:

  Moving and hopping text
  ----------------------------------------
  Left/Right       | Move the cursor
  Shift-Left/Right | Extend the cursor
  Ctrl-Left/Right  | Shrink the cursor
  Alt-Left/Right   | Hop the selected text

  Deleting text
  -------------------------------------
  Backspace | Delete the previous unit.
  Delete    | Delete the selected text.

  Inserting text and changing modes
  ------------------------------------------------------
  [text] | Insert the letter and move to character mode.
  Enter  | Break the paragraph.
  Tab    | Move to the next mode.
