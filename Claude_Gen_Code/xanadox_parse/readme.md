This python script parses Xanalink files from the following archive:
https://archive.org/details/xanadox

```
python3 xanalink_extract.py
usage: xanalink_extract.py [-h] [-s SOURCES] [-o OUTDIR] [--combined COMBINED]
                           inputs [inputs ...]
xanalink_extract.py: error: the following arguments are required: inputs
```
