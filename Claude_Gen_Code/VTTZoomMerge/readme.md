Scripts for producing a markdown file from a VTT file (ex: downloaded from Youtube using yt-dlp) and a Zoom chat log saved from a meeting.
Edit the meeting start timestamp in merge.sh if you want to merge a chat log.  Otherwise use nochat.sh.
These shell scripts expect only one .vtt file and one .txt file in the directory where they are run (in order to simplify the command line).
Move the source files and resulting .md file to another directory after each run.
